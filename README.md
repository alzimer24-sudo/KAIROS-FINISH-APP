# KAIROS FINISH — V11 (prova)

Interfaccia web Android/tablet per cronometraggio sci. Include gestione concorrenti, importazione CSV, simulazione partenze/arrivi, cronometro visivo ai centesimi, risultati, classifiche, esportazione CSV e modalità offline tramite PWA dopo il primo caricamento in HTTPS.

**Attenzione: versione dimostrativa.** Non è ancora collegata al firmware Heltec FINISH e non costituisce un sistema di cronometraggio ufficiale. L'orologio del telefono serve per visualizzare tempi simulati; i tempi reali dovranno arrivare dalla Heltec. Non usare con dati personali reali né per allenamenti ufficiali.

Questo repository contiene solo l'app, non il firmware delle schede. La gestione di account, gruppi e sincronizzazione cloud non è ancora disponibile. La pubblicazione pubblica espone il codice dell'interfaccia, non i dati salvati localmente negli altri dispositivi.
